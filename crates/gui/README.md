# tgradish-gui

Desktop GUI for [tgradish](https://github.com/sliva0/tgradish), built
with egui: a list of files, each with its own settings, a preview to
crop and trim it, and its result.

This crate is internal to tgradish and shares its version. Install
`tgradish` and run `tgradish gui` to use it.
