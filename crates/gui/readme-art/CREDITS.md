# README screenshot art

Images loaded by `readme_screenshot` in `src/screenshots.rs` to produce
the README screenshot. Excluded from published crate packages.

All images are from the **Sunny Land 2D Pixel Art Pack** by **Luis Zuno
(ansimuz)**, released under **CC0** (public domain). As the pack's
`public-license.txt` states: "Public domain and free to use on whatever
you want, personal or commercial. Credit is not required but
appreciated." The pack's music by Pascal Belisle has different terms and
is not included.

  (listed as CC0) and <https://ansimuz.itch.io/sunny-land-pixel-game-art>
  (Creative Commons Zero v1.0 Universal)
